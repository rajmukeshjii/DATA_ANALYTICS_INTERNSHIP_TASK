# NHS Mental Health Analytics Project

## Overview

This project was completed as part of a Data Analytics Internship focused on analysing mental health datasets from publicly available UK healthcare and public health sources. The objective was to apply data analytics techniques to explore mental health service performance, suicide trends, crisis indicators, and NHS benchmarking metrics.

The project involved data cleaning, exploratory data analysis (EDA), KPI extraction, trend analysis, dashboard development, and client-ready reporting using Python, Power BI, and Excel.

---

## Project Objectives

* Analyse UK mental health datasets using Python and Power BI.
* Perform data cleaning and exploratory data analysis.
* Extract key performance indicators (KPIs).
* Identify trends and patterns in mental health services.
* Build interactive dashboards for decision-making.
* Produce client-ready insight reports and recommendations.

# Week 4 – Samaritans Crisis Trends Analysis

## Tasks Completed

### Suicide Trends Analysis

Using official England and Wales suicide statistics:

* Long-term trend analysis (1981–2024)
* Male vs Female analysis
* Regional variation analysis
* Crisis trend reporting

### Key Findings

* 6,190 suicide deaths recorded in 2024
* Male deaths significantly exceeded female deaths
* North East recorded the highest regional suicide rate
* London recorded the lowest regional suicide rate

### Outputs

* Crisis Trend Charts
* Regional Variation Analysis
* Client Insight Report
* Recommendations Report

### Skills Applied

* Time Series Analysis
* Public Health Analytics
* Data Visualisation
